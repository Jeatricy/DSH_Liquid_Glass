# 验证记录 · 1.2.0

验证环境：DSH 桌面版 0.2.1-rc.5，Windows 10，Electron 44.7.0；浏览器回归使用 Chrome 156。本记录描述功能交付时的检查，不代表对所有 DSH 版本和操作系统的兼容承诺。

## 已验证的改动

- 左右侧栏使用相同的 24px 圆角、玻璃底色、高光边框和上下留白。
- 整页额外套框已移除：AppFrame 无边框、无圆角、无偏移，恢复全视口；各功能面板仍保留圆角。
- 折射渲染、SVG 位移贴图、强度控件和“减少透明效果”开关已删除。
- 旧 `refraction` / `solid` 偏好被忽略，后续保存会移除；配色、开关、材质、厚度与虚化设置保留。
- 清透玻璃、柔雾磨砂、四组配色和厚度控制可用。

## 自动检查

- 35 项 Node/jsdom 单元测试通过：偏好校验与迁移、存储拒绝、跨窗口同步、启停与卸载、原生主题与宿主样式保留、样式监听及清理。
- 四组浏览器场景通过：浅色 1360×900、深色 1360×900、小屏 390×844、减少动效 1100×840。
- 非小屏场景使用实际 rc.5 DockKit CSS 检查右栏内部宽度、双列分栏、全屏、收起/重开；浮动面板的视口位置与点击行为保持正常。
- 各场景检查输入、Escape、焦点恢复、控件移除、视口无额外溢出，以及禁用与卸载。

可以运行 `pnpm test` 重现单元测试。浏览器回归需要自行准备官方 SDK 参考资源，步骤见 [开发说明](../README.md#开发与验证)。

## 实机与公开材料

在现有 DSH 桌面窗口中检查了右栏开始页、整体框架和精简后的设置面板。功能交付时核对了本地安装文件与构建产物的一致性。

公开仓库只包含可复现测试和不含个人数据的[离线示例图](images/preview.png)。个人会话截图、机器配置和原始测试报告保留在本地，未包含在仓库中。浏览器测试生成的报告位于 `artifacts` 目录，并由 Git 忽略。

Windows 原生外轮廓和右上三键仍由桌面壳管理。本插件未修改系统窗口区域，也没有创建替代 DSH 服务。
